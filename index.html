Publish to TikTok from your n8n workflows.

PublishFlow connects n8n to the TikTok Content Posting API, so you can schedule uploads, watch publish status, and pull video metrics back into any automation — without touching TikTok's API directly.

See how it works View on GitHub

What it does

01

Publish on schedule

Trigger a workflow on a timer, a form submission, or an upstream event, and PublishFlow uploads the video to the connected TikTok account.

Track publish status

TikTok processes uploads asynchronously. PublishFlow polls the status endpoint and reports back PROCESSING, PUBLISH_COMPLETE, or the failure reason.

Pull metrics back

Read view, like, comment, and share counts for videos your workflow published, so downstream nodes can report or react to performance.

How a run works

02
1

Connect a TikTok account

Authorize PublishFlow once, from inside n8n, using TikTok's OAuth flow. n8n stores the access and refresh tokens as an encrypted credential — PublishFlow never sees your TikTok password.

oauth2 / user consent screen
2

Add the node to a workflow

Drop the PublishFlow node after whatever produces your video: a form, cloud storage, a rendering step, or another API. Point it at the file and set a caption, privacy level, and audience settings.

workflow canvas
3

PublishFlow talks to TikTok

The node initializes an upload, sends the video, and polls until TikTok finishes processing it. Every call and response is logged in the n8n execution so failures are easy to trace.

content posting api
4

Your workflow continues

On success, PublishFlow outputs the published video's ID and share URL, ready for the next node — a Slack message, a spreadsheet row, or a scheduling database.

output

Built for review

03

PublishFlow requests only the TikTok scopes it needs to publish and read back the videos your own workflows create. It does not read your existing content library, does not message on your behalf, and does not store video files after a run completes.

A full breakdown of the scopes requested, the data handled, and where it lives is on the workflow page. Data handling and retention are covered in the privacy policy.
